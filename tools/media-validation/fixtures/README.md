# Media validation fixtures

These two-second, 320×180 synthetic fixtures are Cinesim test assets licensed under MIT. They carry
the same moving test pattern and 440 Hz tone in two representative browser media combinations:

- `h264-aac.mp4`: H.264 baseline video and AAC audio.
- `vp9-opus.webm`: VP9 video and Opus audio.

They are intentionally small, deterministic, and contain no third-party footage.
