This page assumes you have assets in the Media Pool. For the model behind any of it, see
[The timeline](../concepts/timeline.mdx).

## Build a sequence from assets

Select assets in the Media Pool in the order you want them, then create a timeline from the
selection. Cinesim places them end to end, creates the tracks it needs, and makes the new sequence
active — in one undo step.

Video files with sound produce reciprocal linked video and audio clips on separate tracks. Ordinary
move, trim, split, and delete edits keep the pair together. Their boundaries may differ for a split
edit without losing the relationship.

## Choose a tool

| Key          | Tool      | Use it to              |
| ------------ | --------- | ---------------------- |
| <kbd>A</kbd> | Selection | Move clips, drag edges |
| <kbd>T</kbd> | Trim      | Adjust an edit point   |
| <kbd>B</kbd> | Blade     | Cut at the pointer     |

Press <kbd>S</kbd> to toggle snapping. While you drag, Cinesim previews the result and shows collision
feedback when a placement would overlap; the edit commits when you release.

## Trim, split, and delete

Drag a clip's edge to trim it. Trimming clamps any existing fades to the new duration.

Option-drag a linked audio or video edge with the Trim tool to change only that component. Extending
the next shot's audio before its picture makes a J-cut; extending the previous shot's audio beyond
its picture makes an L-cut. The gesture is bounded by available source media and commits one command
and one undo step.

Split the selected clip at the playhead with <kbd>⌘&#92;</kbd>, or cut anywhere with the Blade tool. A
split preserves the outer fades and clears the two new interior edges.

Delete the selection with <kbd>⌫</kbd>. On linked clips, every one of these applies to the pair as a
single edit.

## Shape fades

Drag a clip's fade handle to set a linear fade-in or fade-out — opacity on video, gain on audio.
Combined fades cannot exceed the clip's duration, and the drag commits as one undo step.

Select an audio clip to set its independent gain, stereo pan, and mute state in the Inspector.
Overlapping clips are summed through the master stereo mix. For deterministic dialogue ducking,
attach a direct effect to a music clip or audio track in JSX:

```jsx
<ducker
  id="duck_music"
  sidechain="track_dialogue"
  reduction={db(-12)}
  attack={milliseconds(80)}
  release={milliseconds(250)}
/>
```

The sidechain must name a different audio track. Cinesim ramps down before an active sidechain clip
and releases afterward, so the same timeline always produces the same automation.

## Author transitions

Transitions are explicit timeline children in canonical JSX. They reference the stable IDs on both
sides of an edit instead of overlapping the clips:

```jsx
<transition
  id="transition_scene"
  from="clip_scene_a"
  to="clip_scene_b"
  kind="wipe"
  duration={seconds(1)}
  easing="ease-in-out"
  direction="left"
  softness={percent(3)}
/>
<audiocrossfade
  id="transition_dialogue"
  from="clip_audio_a"
  to="clip_audio_b"
  duration={milliseconds(400)}
  curve="equal-power"
/>
```

The incoming clip needs at least the transition duration before its selected source `in` point.
Transition diamonds appear at their edit points in the full timeline. Picture and audio transitions
remain independent canonical elements.

## Animate typed properties

Place an `animate` block under a clip, effect, caption cue, mask, or other scene node. Its `property`
must name an existing typed property, it must contain at least two keys at unique local times, and
every value must retain the property's type. Supported easing is `linear`, `hold`, `ease-in`,
`ease-out`, or `ease-in-out`.

```jsx
<blur id="blur_focus" radius={px(0)}>
  <animate property="radius">
    <key at={seconds(0)} value={px(0)} easing="linear" />
    <key at={seconds(1)} value={px(24)} easing="ease-in-out" />
  </animate>
</blur>
```

The Effects workspace uses the ordinary project viewer and timeline. Its capability-backed browser
shows effects that execute in preview, and its keyframe editor can add a key at the playhead, move
it, change any typed value or easing, and delete it while retaining the required two keys. Each
completed control gesture is one validated command and one global undo step.

## Manage tracks

Add video, overlay, or audio tracks and rename, mute, lock, or reorder them. Index `0` is the
uppermost track, and upper visual tracks composite over lower ones.

To remove a track, first unlock it and clear its clips — Cinesim refuses to remove a track that
still holds anything.

Adjust track height and timeline zoom to taste; neither is a project edit, so neither enters undo
history.

## Play back your cut

| Key                                    | Action                  |
| -------------------------------------- | ----------------------- |
| <kbd>Space</kbd>                       | Play or pause           |
| <kbd>J</kbd> <kbd>K</kbd> <kbd>L</kbd> | Reverse, pause, forward |
| <kbd>←</kbd> <kbd>→</kbd>              | Previous or next frame  |
| <kbd>Home</kbd>                        | Go to the beginning     |

The viewer offers fit, 50%, 100%, and 200% display scales, configurable grids and safe-area guides,
and fullscreen. Its header reports whether you are watching **Proxy** or **Original** media.

Hovering an asset in the Media Pool previews that source in the viewer and restores your timeline
frame when you leave — timeline transport and source preview stay separate.

## Undo

Press <kbd>⌘Z</kbd> to reverse one completed gesture, not a fragment of one. Panel resizes, selection, zoom,
and track height are interface state and never appear in history.
