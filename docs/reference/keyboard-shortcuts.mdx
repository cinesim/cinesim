---
title: Keyboard shortcuts
description: Every shortcut in the desktop app, by scope.
---

Press <kbd>⌘/</kbd> in the app to open this list in a searchable dialog. On Windows and Linux,
substitute <kbd>Ctrl</kbd> for <kbd>⌘</kbd>.

## Navigation

| Action                  | Shortcut               |
| ----------------------- | ---------------------- |
| Go Home                 | <kbd>⌘⇧H</kbd>         |
| Toggle left sidebar     | <kbd>⌘B</kbd>          |
| Toggle agents sidebar   | <kbd>⌥⌘B</kbd> (macOS) |
| Show keyboard shortcuts | <kbd>⌘/</kbd>          |

## Projects

Available on the Home screen.

| Action              | Shortcut                    |
| ------------------- | --------------------------- |
| Open project        | <kbd>⌘O</kbd>               |
| Open recent project | <kbd>⌘1</kbd>–<kbd>⌘9</kbd> |

## Project sections

| Action | Shortcut      |
| ------ | ------------- |
| Media  | <kbd>⌘1</kbd> |
| Edit   | <kbd>⌘2</kbd> |

## Edit tools

| Action               | Shortcut          |
| -------------------- | ----------------- |
| Selection tool       | <kbd>A</kbd>      |
| Trim tool            | <kbd>T</kbd>      |
| Blade tool           | <kbd>B</kbd>      |
| Toggle snapping      | <kbd>S</kbd>      |
| Split selected clip  | <kbd>⌘&#92;</kbd> |
| Delete selected clip | <kbd>⌫</kbd>      |

## Viewer transport

| Action                  | Shortcut                               |
| ----------------------- | -------------------------------------- |
| Play or pause           | <kbd>Space</kbd>                       |
| Reverse, pause, forward | <kbd>J</kbd> <kbd>K</kbd> <kbd>L</kbd> |
| Previous or next frame  | <kbd>←</kbd> <kbd>→</kbd>              |
| Go to the beginning     | <kbd>Home</kbd>                        |
