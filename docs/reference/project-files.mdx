## Directory layout

```text
documentary-cut/
├── cinesim.toml
├── main.jsx
├── components/             optional relative source modules
├── AGENTS.md
├── .gitignore
└── .video/
    ├── cache/
    ├── compiler/
    ├── filmstrips/
    ├── frames/
    ├── originals/
    ├── proxies/
    ├── runtime/
    ├── thumbnails/
    ├── transcripts/
    └── waveforms/
```

| Path                                          | Contents                                                                                             | Canonical |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------- | --------- |
| `cinesim.toml`                                | Format/language versions, identity, active composition, settings, compiler policy, and asset catalog | Yes       |
| `main.jsx` and reachable `.js`/`.jsx` modules | Compositions, timelines, tracks, clips, graphics, effects, and animation                             | Yes       |
| `AGENTS.md`                                   | Project guidance for connected agents                                                                | Yes       |
| `.gitignore`                                  | Excludes `.video/`                                                                                   | Yes       |
| `.video/`                                     | Generated media, compiler artifacts, and runtime state                                               | No        |

There is no separate asset file or JSON timeline in format v2. Timeline structure exists once in
source and compiles to deterministic semantic IR in memory. Source imports must be relative, stay
inside the real project root, and may not resolve packages or symlink escapes.

## `cinesim.toml`

The manifest is the non-video-source authority:

```toml
format_version = 2
language_version = 1

[project]
id = "project_example"
name = "Example"
entry = "main.jsx"
active_composition = "sequence_main"

[settings]
autosave = true
preview_quality = "half"
background_color = "#09090b"
filmstrip_interval_seconds = 5
proxy_generation = "automatic"
proxy_profile = "balanced"
proxy_max_long_edge = 1280
proxy_frame_rate_cap = 60
proxy_quality = "medium"

[compiler]
strict = true

[assets.asset_interview]
kind = "video"
name = "Interview"
duration_us = 12000000
width = 1920
height = 1080
frame_rate = 30
has_audio = true

[assets.asset_interview.source]
kind = "local"
path = "/Volumes/Footage/interview.mov"
```

Asset table keys are stable IDs used by source expressions such as
`asset("asset_interview")`. Cinesim patches owned keys and asset blocks with expected revisions, so
comments and unknown tables survive unrelated edits.

## Video source

The source language uses JavaScript module syntax and lowercase JSX-shaped primitives, but it is
not React and is never executed as JavaScript:

```jsx
export const main = (
  <composition id="sequence_main" name="Main" width={1920} height={1080} fps={30}>
    <timeline id="timeline_main">
      <track id="track_video_1" kind="video" name="Video 1">
        <clip
          id="clip_interview"
          asset={asset("asset_interview")}
          media="video"
          start={seconds(0)}
          in={seconds(2)}
          duration={seconds(5)}
        />
      </track>
    </timeline>
  </composition>
);

export default main;
```

Capitalized imports are reusable user components. Components may generate visual content inside an
explicit clip; editable composition, timeline, track, and clip structure remains explicit.

## `.video/`

`.video/` contains caches, proxies, perception artifacts, compiler transactions, and runtime
checkpoints. It is ignored as a unit and must not become creative source of truth. Source media is
referenced in place by the manifest; no project-level `media/` or `exports/` directory is required.

## Version control and migration

Commit `cinesim.toml`, video source, and ordinary project documents. Do not commit `.video/`.
Opening a format-v1 project offers a one-time migration that creates a recoverable sibling backup,
generates format-v2 source, recompiles it, verifies semantic equivalence, and only then removes the
legacy active files.
