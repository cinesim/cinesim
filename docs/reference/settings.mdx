---
title: Project settings
description: Every project setting in cinesim.toml, with types and defaults.
---

Project editing preferences live in the `[settings]` table of `cinesim.toml`. Cinesim validates the
whole manifest on load and rewrites only the changed key, preserving unrelated comments and tables.

```toml
[settings]
autosave = true
preview_quality = "half"
background_color = "#09090b"
filmstrip_interval_seconds = 5
proxy_generation = "automatic"
proxy_profile = "balanced"
proxy_max_long_edge = 1280
proxy_frame_rate_cap = 60
proxy_quality = "medium"
```

| Key                          | Values or type                                      | Default     |
| ---------------------------- | --------------------------------------------------- | ----------- |
| `autosave`                   | boolean                                             | `true`      |
| `preview_quality`            | `full`, `half`, `quarter`                           | `half`      |
| `background_color`           | `#rrggbb`                                           | `#09090b`   |
| `filmstrip_interval_seconds` | positive number                                     | `5`         |
| `proxy_generation`           | `automatic`, `manual`                               | `automatic` |
| `proxy_profile`              | `space-saver`, `balanced`, `high-quality`, `custom` | `balanced`  |
| `proxy_max_long_edge`        | integer 320–7680                                    | `1280`      |
| `proxy_frame_rate_cap`       | `30` or `60`                                        | `60`        |
| `proxy_quality`              | `low`, `medium`, `high`                             | `medium`    |

Lower preview quality trades image detail for decode headroom and does not alter rendered output.
Named proxy profiles set the final three proxy keys; choose `custom` to control them independently.
Cloud originals always receive an edit proxy.

Account-scoped transcription preferences remain in desktop application state, not in the project
manifest, and therefore do not enter project history.
