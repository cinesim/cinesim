---
title: Cinesim
description: A local-first video editor where the desktop app, the CLI, and coding agents all edit the same project.
---

Cinesim is a nonlinear video editor that keeps your project on your own disk as ordinary files. The
desktop app, the `cinesim` CLI, and any coding agent you connect all make edits through the same
validated command layer — so there is one project state, and every tool sees it.

## Find your way around

**[Concepts](/docs/concepts/projects)** explain the model: what a project is, how the timeline is
structured, and why every edit is a command. Read these once and the rest of the docs will make
sense.

**[Guides](/docs/guides/import-media)** are task-shaped. They assume you have a project open and
want to get something specific done.

**[Reference](/docs/reference/cli)** is for lookup: every CLI command, every MCP tool, every
settings key, every keyboard shortcut.

**[Internals](/docs/internals/architecture)** is written for people working on Cinesim itself
rather than with it — architecture, design decisions, and the current state of the build.

<Callout type="info">
  Cinesim is in active development and there is no packaged release yet. You run it from source, and
  some behavior described here is still being validated. [Project status](/docs/internals/status)
  tracks what is finished and what is not.
</Callout>
