There is no packaged release yet, so you run Cinesim from a clone of the repository. This page gets
the desktop app open. You only need the second half if you want accounts or cloud projects.

## Requirements

| Requirement    | Version         | Needed for                             |
| -------------- | --------------- | -------------------------------------- |
| Node.js        | 22.12 or newer  | Everything                             |
| pnpm           | 11.22.0         | Everything                             |
| macOS          | Current release | Desktop app (the only tested platform) |
| Docker Desktop | Current release | Accounts and cloud projects only       |

## Run the desktop app

```bash
git clone <repository-url> cinesim
cd cinesim
pnpm install
pnpm dev
```

`pnpm dev` builds the Electron main, preload, and renderer targets, starts a Vite dev server, and
launches the app. It watches all three targets, so you can leave it running.

You now have a working editor. It does not need an account, a network connection, or any of the
services below — go to the [quickstart](./quickstart.mdx) and make a cut.

## Run the CLI

The CLI reads and edits the same projects the desktop app does:

```bash
pnpm cli project inspect --json
```

From a clone, `pnpm cli` is the reliable invocation. The binary itself is named `cinesim` (with
`video` as a temporary alias), which is how it will be invoked once Cinesim ships as a package. See
the [CLI reference](../reference/cli.mdx) for the full command list.

## Optional: accounts and cloud projects

Cloud projects store your originals privately under your account. They need PostgreSQL for the
control plane and an SMTP server for verification email; both run in Docker locally.

Start Docker Desktop, then:

```bash
pnpm auth:setup
```

That command creates an ignored `apps/api/.env.local` with a random secret, starts pinned PostgreSQL
and Mailpit containers, waits for the database, and applies the committed migrations. It does not
launch Electron, and it never overwrites secrets you have already set.

Then start everything together:

```bash
pnpm dev:local
```

This starts the local services, watches the auth browser bundle and the Hono API, waits for the API
to report ready, and then starts the desktop app.

| Service               | Address                 |
| --------------------- | ----------------------- |
| API and sign-in page  | `http://127.0.0.1:8787` |
| Desktop auth callback | `http://127.0.0.1:8788` |
| Mailpit inbox         | `http://127.0.0.1:8025` |
| PostgreSQL            | `127.0.0.1:54329`       |

Verification email is captured by Mailpit rather than sent — open the inbox to click through a
signup. Stop the containers without losing their data using `pnpm auth:down`.

Cloud storage itself stays disabled until you also supply Cloudflare R2 credentials. Setting those
up is covered in [Cloud originals](../internals/cloud-storage.mdx#development-setup).
