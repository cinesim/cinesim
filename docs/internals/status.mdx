Cinesim compiles, type-checks, tests, and builds. It has not had a full interactive pass against a
broad codec and GPU matrix. This page separates automated verification from the remaining
interactive work so nobody has to guess which is which.

<Callout type="warn">
  Anything under [Not yet verified](#not-yet-verified) is implemented and passing its automated
  checks but has not been exercised through the full interactive workflow.
</Callout>

## Built and tested

**Project model.** Deterministic serialization, version rejection, stable ID allocation,
undo and redo, and the full command set: asset import and cascading removal; timeline creation from
ordered assets and safe removal; track add, update, remove, and reorder; clip add, remove, move,
trim, and split.

**Authoring pathway.** Zod-validated UI commands and directly edited source converge at one compile
acceptance boundary. Invalid disk candidates retain last-known-good playback. MCP exposes no
canonical edits.

**Playback engine.** Monotonic clock, frame-cadenced scheduling, bounded sequential cursors,
latest-only seek coalescing, source-preview isolation and restoration, WebGPU composition, and Web
Audio scheduling.

**Finishing and export.** Split edits, captions, validated picture/audio transitions, adjustment
layers, typed effects and keyframes, deterministic scoped WebGPU render passes, and explicit
H.264/AAC Rec.709 SDR MP4 export with bounded interleaved video/audio encoding and atomic
publication. UI and MCP expose preset, range, progress, status, and cancellation controls.

**Derived media.** Bounded thumbnail, filmstrip, and waveform generation with atomic publication,
storage accounting, recovery, and eviction ordering.

**Accounts and cloud.** Better Auth with Hono, PostgreSQL, Drizzle migrations, Mailpit email
verification, conditional Google OAuth, and Electron PKCE. Cloud project catalog, quota reservation,
resumable multipart upload, and transfer containment.

**Desktop UI.** Home with separate Cloud and Local groups; media import and bin; timeline creation
from ordered selection; track creation, rename, mute, lock, reorder, and safe removal; selection,
trim, and blade tools; snapping and collision feedback; filmstrip frames and waveforms; viewer with
source and timeline modes, display scales, grids, safe-area guides, fullscreen, frame stepping, and
transport shortcuts; Metrics and Agents sidebars; settings.

**Local agents.** Claude Code and Codex sessions with normalized transcripts, per-session model and
effort controls, approval modes, direct project-local file/shell capabilities, managed shared
guidance, and an authenticated project-scoped MCP endpoint. Read-only change summaries remain in
chat; accepted source generations enter only ordinary top-bar project history.

Verification currently passing: whole-repository TypeScript check, Vite+ format and lint with no
warnings, the automated test suite, production builds for main, preload, renderer, API, and web, and
a CLI smoke check.

## Not yet verified

- Interactive Electron, Web Audio, real-media codec, and GPU-driver behavior.
- Worker-based thumbnail, filmstrip, and proxy paths with real footage.
- Interactive browser, email, and custom-protocol authentication flows.
- Provider compatibility with specific installed versions of Claude Code and Codex.

No benchmark numbers are published. The Metrics sidebar exposes live FPS, seek latency, request
coalescing, dropped frames, GPU-submit duration, artifact jobs, and storage — but representative
measurements need the interactive pass above.

## Known limitations

**Editing model.** The source format supports multiple explicit compositions, typed animations,
effects, transitions, generated visual content, captions, adjustment layers, masks, and linked or
split A/V commands. Nested composition playback remains future work.

**Concurrency.** Desktop commands and the legacy CLI command adapter share a cross-process project
lock and reject stale generations instead of overwriting a newer edit. MCP is not a canonical writer.
The desktop watches the complete canonical file graph, retains its last-known-good program through
invalid saves, publishes diagnostics, and live-refreshes when external source becomes valid again.

**Media.** Exact-frame jobs generate bounded asset frames through Mediabunny/WebCodecs and accepted
timeline frames through the production WebGPU compositor. There is no bundled FFmpeg, so footage
Chromium cannot decode cannot be proxied. Still-image import is not exposed in the media picker.

**Audio.** The rolling Web Audio mix and bounded export mixer execute exact clip ranges, fades, gain,
stereo pan, mute, equal-power crossfades, and deterministic sidechain ducking. Interactive playback
is not an AudioWorklet.

**Other.** The Notes panel projects canonical project and asset TOML records plus lowercase
timeline `<note>` elements; edits use validated commands and accepted project history. The
renderer application chunk is around 1.5 MB minified; lazy route and vendor splitting is pending.
